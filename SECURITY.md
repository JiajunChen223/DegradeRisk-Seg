# Security Policy

This repository contains research code and lightweight metadata. It should not contain private credentials, private datasets, trained checkpoints, or unpublished manuscript files.

## Reporting a Vulnerability

Please open a private security advisory on GitHub if available, or contact the maintainers through the repository owner profile. Include:

- A concise description of the issue.
- Steps to reproduce it.
- The affected commit or release.
- Any relevant logs or stack traces with sensitive paths removed.

## Supported Versions

Security fixes are handled for the latest public release of this repository.
