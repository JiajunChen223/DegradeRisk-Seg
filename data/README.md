# Data Directory

This repository tracks only lightweight metadata required by the paper code:

- `processed/split_manifests/plotrice_v1_official_split.csv`
- `processed/canonical/normalization_*_plotrice_v1.json`

Do not commit official Plot-Rice zip archives, unpacked arrays, generated `.npz` files, checkpoints, or derived experiment outputs. The default configs expect the official Plot-Rice v1.0 zip packages in a sibling directory named `PlotRice-V1.0`.
